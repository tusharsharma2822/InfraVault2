Embeddings and References

| Data             | Strategy  | Reason                                |
| ---------------- | --------- | ------------------------------------- |
| Tags             | Embed     | Document ke saath naturally belong    |
| File metadata    | Embed     | Same lifecycle                        |
| Preview metadata | Embed     | Same document lifecycle               |
| Project          | Reference | Independent entity                    |
| Uploader         | Reference | Independent user                      |
| Audit actor      | Reference | User independently exists             |
| OTP user         | Reference | Challenge temporary, user independent |

Final Index Blueprint

	USERS
	────────────────────────
	email UNIQUE


	OTP_CHALLENGES
	────────────────────────
	expiresAt TTL
	userId + createdAt


	PROJECTS
	────────────────────────
	projectCode UNIQUE
	status


	DOCUMENTS
	────────────────────────
	projectId
	uploadedBy
	tags
	createdAt DESC
	projectId + createdAt DESC
	search index strategy


	AUDIT_LOGS
	────────────────────────
	actorId + createdAt DESC
	resourceId + createdAt DESC
	action + createdAt DESC


	REFRESH_TOKENS
	────────────────────────
	expiresAt TTL
	userId
	tokenHash lookup strategy

Final Architecture Breeze

	1.	Database
		  ↓
		MongoDB
		
	2.	Core Collections
			  ↓
			users
			otp_challenges
			projects
			documents
			audit_logs
			refresh_tokens
			
	3.	Tags
		  ↓
		Embedded Array
		
	4.	Project
		  ↓
		Referenced by ObjectId
		
	5.	Uploader
		  ↓
		Derived from authenticated JWT identity
		
		Binary Files
		  ↓
		NOT stored as normal MongoDB metadata documents
		  ↓
		External Storage Layer
		
	6.	OTP
		  ↓
		Hashed
		Expiring
		Attempt Limited
		TTL Cleaned
		
	7.	Search
		  ↓
		Metadata + Tags + Index Strategy
		
	8.	Preview
		  ↓
		Embedded Preview Metadata
		  ↓
		Actual Preview Binary in Storage
		
	9.	Audit
		  ↓
		Append-oriented event history
		
	10. Sessions
		  ↓
		Hashed Refresh Token Records
